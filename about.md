## Services Folder

### services/auth-service/

Implemented Node.js authentication service.

- .env
  - Local environment variables such as MONGO_URI and JWT settings.
- package.json
  - Service metadata, scripts, and dependencies.
- package-lock.json
  - Dependency lock file generated by npm.
- server.js
  - Service entry point.
  - Connects to MongoDB.
  - Registers auth routes.
  - Starts Express server on port 3000.

### services/auth-service/src/

Source code for auth-service.

- app.js
  - Creates the Express app.
  - Registers core middlewares: morgan, express.json, cookie-parser.

- config/config.js
  - Loads env vars using dotenv.
  - Exposes config object with MONGO_URI and JWT_SECRET.

- db/db.js
  - Handles MongoDB connection via mongoose.
  - Uses a short server selection timeout and returns success/failure status.

- model/user.model.js
  - Defines userSchema and userModel.
  - Fields: email, fullname.firstName, fullname.lastName, password, googleID, role.

- controller/auth.controller.js
  - Contains auth controller logic.
  - register handler validates duplicate email, hashes password, creates user, signs JWT, sets cookie, and returns user without password.

- middlewares/validation.middleware.js
  - Request validation helpers for register route using express-validator.
  - Exports registerUserValidationRules.

- routes/auth.routes.js
  - Defines auth endpoints.
  - Currently includes POST /register with validation + controller handler.
