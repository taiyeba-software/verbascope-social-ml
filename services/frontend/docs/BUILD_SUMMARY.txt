================================================================================
                          AUTHENTICATION FLOW
================================================================================

Register Flow:
  1. User → /auth/register
  2. Fills: firstName, lastName, email, password
  3. Form validation (client-side)
  4. Submit → POST /api/auth/register
  5. Backend validates & creates user
  6. Backend sets httpOnly cookie
  7. Backend publishes user_created event
  8. Frontend redirects → /feed

Login Flow:
  1. User → /auth/login
  2. Fills: email, password
  3. Form validation
  4. Submit → POST /api/auth/login
  5. Backend validates credentials
  6. Backend sets httpOnly cookie
  7. Frontend redirects → /feed

Google OAuth Flow:
  1. Click "Continue with Google"
  2. → GET /api/auth/google
  3. Google auth dialog
  4. User approves
  5. → GET /api/auth/google/callback
  6. Backend creates/updates user
  7. Backend sets httpOnly cookie
  8. Backend redirects → http://localhost:3002/feed

================================================================================
                            TROUBLESHOOTING
================================================================================

If you get errors, check:

1. Backend Services Running?
   → Auth service on port 3000: npm run dev
   → Notification service on port 3001: npm run dev

2. Dependencies Installed?
   → pnpm install

3. Port 3002 Available?
   → lsof -i :3002 (macOS/Linux)
   → netstat -ano | findstr :3002 (Windows)

4. Styles Not Loading?
   → Clear browser cache
   → Restart dev server: pnpm dev

5. TypeScript Errors?
   → pnpm tsc --noEmit
   → Check types/index.ts

6. API Connection Fails?
   → Check CORS headers in backend
   → Verify withCredentials: true
   → Check network tab in DevTools

See QUICKSTART.md for full troubleshooting guide.
